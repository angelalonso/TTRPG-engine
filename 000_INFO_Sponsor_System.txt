MOTORSPORT SPONSORSHIP NEGOTIATION SIMULATION REFERENCE GUIDE
================================================================================

This guide outlines realistic values, achievement multipliers, and valuation 
matrices for building a motorsport sponsorship negotiation engine.

--------------------------------------------------------------------------------
1. MOTORSPORT TIER & ACHIEVEMENT MULTIPLIERS
--------------------------------------------------------------------------------

In racing, achievements (Poles, Wins, Podiums) are weighted heavily by the 
competition level. Use these tier benchmarks to establish a racer's baseline 
prestige multiplier ($M$).

TIER / CATEGORY LEVEL           EXAMPLE SERIES                               BASE VALUE / YR      TIER MULTIPLIER (M)
----------------------------------------------------------------------------------------------------------
Tier 1: Amateur / Club Racing   Amateur, HotHatch 200                        $2k - $30k           1.0x (Base)
Tier 2: Entry Pro / Junior      HotHatch 300, Caterham, Porsche cup, Radical $30k - $250k         1.5x - 2.5x
Tier 3: Elite Regional/Feeder   BTCC, GTO                                    $100k - $800k        3.0x - 6.0x
Tier 4: Premier National/World  N-GT                                         $250k - $3M          8.0x - 15.0x
Tier 5: Global Apex             GT                                           $1M - $50M+          25.0x - 50.0x


REALISTIC WEIGHTING PER ACHIEVEMENT (POINTS/VALUE MULTIPLIERS):
- Pole Position:          1.0x Base Weight
- 3rd Place (Podium):     1.5x Base Weight
- 2nd Place (Podium):     2.0x Base Weight
- 1st Place (Win):        3.5x Base Weight
- Championship Victory:  10.0x Base Weight

3. SUGGESTED SIMULATION LOGIC FORMULAS
--------------------------------------------------------------------------------

1. Racer Value Score (Vr):
   Vr = Tier Multiplier * SUM[ (Poles * 1.0) + (Podiums * 1.8) + (Wins * 3.5) + (Titles * 10.0) ]

2. Total Offered Sponsorship Value (Vs):
   Vs = Cash Payments + In-Kind Value (Gear/Car/Maintenance) + Expected Bonus Outlay

3. Negotiation Acceptance Ratio (Vs / Vr):
   - Ratio between 0.9 and 1.1  --> High Acceptance Probability (Fair Deal)
   - Ratio < 0.7               --> Racer Rejects (Underfunded Offer)
   - Ratio > 1.3               --> Sponsor Rejects (Demands Exceed Driver Prestige)
