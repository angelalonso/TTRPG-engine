GTR2 setup

Start GTR2 and select Hot Hatch 200 Championship - Round 4: Snetterton.

Use the event track and configure the required car/equipment: alfa_mito, citroen_ds3, ford_fiesta, seat_ibiza, vauxhall_corsa, peugeot_207, toyota_yaris, renault_clio, helmet.
