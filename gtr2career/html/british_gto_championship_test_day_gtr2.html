GTR2 setup

Start GTR2 and select British GTO Championship Test Day.

Use the event track and configure the required car/equipment: tvr_t400r, mosler_mt900r, porsche_biturbo, morgan_aero, gillet_vertigo, bmw_z3mcoupe, nissan_350z, bmw_m3_gtr, helmet.

Run the event, then continue to import or enter the results in the engine.
